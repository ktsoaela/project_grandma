## Your First Recording - 5 Minutes

### Step 1: Open Project Grandma
Launch the application - you should see the main window.

### Step 2: Configure Options
Before you start recording:

- **Number of Screenshots**: Keep default (25) or adjust
- **Record Video** (Optional): Enable if you want an MP4 video
- **Export Format**: Pick what format you want (HTML is default)

Example for beginners:
```
Screenshots: 25
Video: ❌ (Unchecked)
Export: ✓ HTML only
```

### Step 3: Click "Start Record"
You'll see the window change:

```
Recording...
[0 steps recorded]
[Add Comment] [Stop Record]
```

### Step 4: Do Your Task
Perform the actions you want to document:
- Click the Start menu
- Open an application
- Navigate to something
- Fill out a form

**Each click = one step** ✓

### Step 5: Add Comments (Optional)
To explain confusing steps:

1. Click **"Add Comment"**
2. Type your explanation
3. Continue with more clicks

### Step 6: Click "Stop Record"
When finished:
1. Click **"Stop Record"**
2. Project Grandma generates your guide
3. Click **"Open"** to view the result

## Your First Guide 🎉

You now have an interactive HTML guide showing:
- ✓ Screenshot of each step
- ✓ What you clicked
- ✓ Your comments
- ✓ Shareable format

## Common Questions

**Q: How long can I record?**
A: As long as you need! There's no time limit.

**Q: Can I edit after recording?**
A: Not directly, but you can export as Markdown and edit the text.

**Q: What if I make a mistake?**
A: Just record again - it's quick and easy!
