## General Questions

**Q: What is Project Grandma?**
A: A step recorder that captures what you do and creates easy-to-follow guides in HTML, PDF, Markdown, or video format.

**Q: How is it different from Windows PSR (Problem Steps Recorder)?**
A: Project Grandma is easier to use, creates better-looking reports, works on macOS too, records video, and exports to more formats.

**Q: Is it free?**
A: Yes! Project Grandma is open-source and completely free to use.

**Q: Can I use it commercially?**
A: Yes! It's under the MIT license - use it for personal or commercial projects.

**Q: Does it work offline?**
A: Yes! No internet needed. Everything runs locally on your computer.

## Recording Questions

**Q: Why isn't my typing being recorded?**
A: For privacy and security, we don't capture typed text (like Windows PSR). We record what you click and where you click it.

**Q: Can I pause recording?**
A: Not yet, but you can add comments to skip steps or explain breaks.

**Q: Can I record for hours?**
A: Yes, but it's better to create multiple shorter guides (5-15 steps each).

**Q: What if I make a mistake during recording?**
A: Just re-record. It takes 5 minutes and you get a cleaner guide.

**Q: Does it record my passwords?**
A: No. We don't capture keyboard input for security reasons.

**Q: Can I edit a recording after saving?**
A: Not directly in the app, but you can:
- Export as Markdown and edit the text
- Re-record to make improvements
- Use image editing software to modify screenshots

## Export Questions

**Q: Why is the HTML file so large?**
A: Because it includes all screenshots embedded directly. It's a complete, standalone file.

**Q: What format should I use?**
A: 
- **Sharing**: HTML (interactive, no software needed)
- **Printing**: PDF (professional, printable)
- **Editing**: Markdown (editable text)
- **YouTube**: Video (engaging, shows motion)

**Q: Can I edit the PDF?**
A: PDFs are generally final products. Export as Markdown if you need to edit.

**Q: How do I reduce file size?**
A: 
- Lower video FPS (3-5 instead of 10)
- Reduce number of steps/screenshots
- Export as Markdown (smallest size)
- Compress files before sharing

## Technical Questions

**Q: What are the system requirements?**
A: 
- Windows 10+ or macOS 10.12+
- 4GB RAM minimum
- 500MB disk space
- Internet optional

**Q: Does it require admin rights?**
A: Windows installer asks for admin, but portable version doesn't need it.

**Q: Can I install on USB?**
A: Yes! Use the portable version.

**Q: What about M1/M2 Mac support?**
A: Yes, the macOS app supports Apple Silicon natively.

**Q: Can I uninstall it easily?**
A: Yes! Windows Control Panel → Add/Remove Programs, or delete the portable exe.

## Usage Questions

**Q: How do I share my guide?**
A: 
- Email the HTML file
- Upload PDF to cloud storage
- Post Markdown to GitHub
- Upload video to YouTube
- Embed HTML on a website

**Q: Can multiple people use it?**
A: Yes, one license per computer. Each person uses their own account.

**Q: How do I create guides for different audiences?**
A: Create separate guides-
- Technical guide (detailed steps)
- User guide (simple steps)
- Video tutorial (entertaining)

**Q: Can I combine multiple recordings?**
A: Not automatically, but you can:
- Export Markdown and merge manually
- Create one long recording
- Export multiple guides and reference them
